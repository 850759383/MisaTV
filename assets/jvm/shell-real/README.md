# assets/jvm/shell-real

这个目录原本放**第三方加固壳的真实实现 jar**（`ftyshinidie.jar` / `foni-spider.jar`）。
它们是从第三方壳里解包/改写出来的产物，版权归各自权利人所有，**不随源码仓库分发**。

影响：只有「壳 jar 里自带 `assets/<壳名>.guard`、且本目录有对应 `<壳名>.jar`」的源
才会走这条纯 Java 快路径（单次 2–3 秒）。

没有这些文件时程序不会失效，而是**回退到原生解包**：
首次调用该源时用 unidbg ARM 桥（设置 → 播放 → 加固壳支持，按需下载）解包一次，
把壳里加密的真实实现缓存为普通 jar，之后同样走快路径。区别只是首次要多等 20–30 秒。
